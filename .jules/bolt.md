## 2024-10-17 - Avoid Unnecessary HTML5 Canvas Re-renders
**Learning:** HTML5 Canvas components that contain internal continuous rendering loops (via `requestAnimationFrame`) can become significant performance bottlenecks if they are placed within a parent component that has frequent state updates, such as a timer component (e.g., `MeditationPlayer` updating `timeRemaining` every second). Each parent re-render unnecessarily tears down and restarts the canvas rendering loop, causing jank and high CPU usage.
**Action:** When using canvas elements with internal loops within frequently re-rendering parents, wrap the canvas component in `React.memo` (using `React.memo<Props>(...)` in React 18+ with TypeScript) to isolate it from the parent's update cycle and prevent redundant re-renders.
