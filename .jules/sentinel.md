## 2025-02-27 - Serverless Admin Authorization Bypass
**Vulnerability:** The internal `api/admin-content.js` serverless function lacked an authorization check, essentially allowing any authenticated user with a valid JWT to access administrative functions and bypass access control to the database's `fitness_content` table (or any other arbitrary table since the `table` property could be manipulated through the request body).
**Learning:** Hardcoding a simple comment like `// TODO: Add strict admin role check here.` is a clear anti-pattern and risk when building APIs. Internal routes, even if undocumented, are discoverable and attackable.
**Prevention:** Implement administrative privileges correctly when setting up the serverless function (e.g. comparing the user's ID to a restricted environment variable like `ADMIN_USER_ID`) before attempting database queries, and strictly limit the parameters an endpoint can dynamically execute (e.g., locking down the tables to specific allowed ones). Ensure that endpoints default to a "fail-secure" response (`403 Forbidden`) instead of making a flawed assumption.
